# StatFlowers v0.1.0 — First Public Preview 🌸

StatFlowers is an interactive 3D botanical studio for exploring procedural flower forms, bloom development and mathematical patterns.

## Highlights

- Eight flower families: rose, tulip, lily, sunflower, daisy, gerbera, coneflower and poppy
- Three-dimensional and overhead views with mouse rotation and zoom controls
- Bud-to-bloom timeline and flower-specific growth animations
- Adjustable petal width, curvature, colour, layers and other family-specific parameters
- Vogel/golden-angle phyllotaxis exploration in composite flower heads
- Procedural Three.js petal meshes, matte materials and soft shadows
- Several geometric and botanical-inspired rose styles
- Open-source MIT-licensed JavaScript and HTML

## Status and limitations

**Experimental public preview.** Flower shapes and growth animations are artistic, mathematically inspired approximations, not validated botanical or cellular-development simulations. Some visual realism remains a work in progress.

The tulip bud has been adjusted to join the stem with a small collar instead of a floating green ball. These late refinements pass JavaScript syntax checks but have not yet received exhaustive browser/device testing.
